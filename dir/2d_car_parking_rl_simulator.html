Markov Decision Process (MDP) Model

1. State Space Representation S

To allow fast tabular Q-learning in browser, the continuous state is discretized into buckets:

  • Relative Position (dx, dy): Discretized distance vector to target slot center.
  • Heading Angle Error (dTheta): Difference between car orientation and target slot angle.
  • LIDAR Sector Clearances: Front, rear, and lateral ray readings binned into proximity zones (Near, Mid, Far).

2. Action Space A (Discrete)

The agent commands 5 discrete actions:

0: Drive Forward + Straight
1: Drive Forward + Left
2: Drive Forward + Right
3: Reverse + Left
4: Reverse + Right

3. Kinematic Bicycle Physics

Calculates realistic non-holonomic vehicle motion using wheelbase $L$:

dx/dt = v · cos(θ)
dy/dt = v · sin(θ)
dθ/dt = (v / L) · tan(δ)

4. Reward Function Formulation

Calculates continuous feedback at each step $t$:

R_t = R_progress + R_align + R_time + R_terminal
  • R_progress: Shaping reward proportional to distance reduction to slot.
  • R_align: Angular alignment bonus $\cos(\theta_{car} - \theta_{target})$.
  • R_terminal: +100 for successful parking, -100 for wall collision.
