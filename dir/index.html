Python Fundamentals · Lesson 5

Functions that give answers back

Functions can do more than perform an action. With a return value, they can calculate a result and hand it back to the part of your program that called them.

Why this mattersA return value lets you reuse a result in a new expression, save it in a variable, or pass it to another function.

From input to output

Think of a function as a small, focused machine. You give it some input through parameters, it performs a task, and then it can send a value back with return.

↳ParameterA named input that a function uses.
∑Return valueThe result a function sends back.
⌘Function callUsing a function by its name.
